02 · 매출 드라이버로 본 4개 노드

테스트 밸류체인은 하나의 시장이 아니다. 매출이 무엇에 연동되는지가 서로 다른 네 개의 노드로 구성되며, 같은 "테스트 수혜주"라도 사이클 타이밍이 갈리는 이유가 여기에 있다.

NODE ①

ATE — 테스터 본체

드라이버: 고객 capex · 테스트 시간

전기 신호를 넣고 판정하는 두뇌. 테스트 시간이 늘어날수록 필요한 테스터 대수가 정비례로 증가한다. 리드타임 6개월+.

Advantest · Teradyne (합산 ~80% 과점)
HBM 테스터는 Advantest T5503 계열이 사실상 표준
NODE ②

접촉 소모품 — 프로브카드 · 소켓

드라이버: 웨이퍼 투입량 × 테스트 강도

칩과 테스터를 잇는 소모품. 설계가 바뀔 때마다 신규 제작, 핀 수 증가는 ASP 상승과 교체 주기 단축을 동시에 만든다.

FormFactor (HBM 프로브카드 70%+) · Technoprobe
국내 — 리노공업 · ISC · 티에스이 · 마이크로프랜드
NODE ③

검사 · 계측

드라이버: 인서션 지점 수

적층·본딩 공정 사이에 새로 끼어드는 검사 스텝. 검사 지점은 칩 물량보다 빠르게 늘어 증분 기울기가 가장 가파른 노드.

KLA · Onto Innovation
하이브리드 본딩 · 16단 적층 · 패널레벨로 갈수록 지점 수↑
NODE ④

핸들링 · 테스트 하우스

드라이버: 물량 · 테스트 아웃소싱

칩을 옮기고 테스트를 실행하는 물류와 실행의 층. 1,000W급 칩 등장으로 발열 제어형 핸들러로 고도화가 진행 중.

프로버 — TEL · TSE · 핸들러 — 코휴 · 테크윙
테스트 하우스(OSAT) — ASE · Amkor · 국내 OSAT
