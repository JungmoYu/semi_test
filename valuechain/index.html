테스트 밸류체인 — HBM의 release gate를 따라가다

산업분석 리포트와 같은 플로우를 기준으로 통일했다. Wafer test에서 KGD를 만들고, die-level 검증과 stack·bond를 거쳐 KGSD를 확보한 뒤, final·burn-in·SLT로 넘어간다. 검사·계측은 이 흐름 위에 겹쳐지는 별도의 공정제어 레이어다.

01 · HBM 테스트 플로우 — 단계를 클릭하세요

최종 테스트 한 번으로 끝나는 구조가 아니라, 조립 가치가 누적될수록 다음 공정으로 넘기기 전에 양품을 확인하는 단계별 release gate가 중요해진다.

Inspection · Metrology — 표면 · 범프 · overlay · warpage · void · subsurface defect를 pre/post-bond 공정 전후에서 겹쳐서 확인
KGD는 불량 다이의 적층 투입을 막고, KGSD는 불량 HBM 스택이 고가 GPU·ASIC 패키징으로 넘어가는 것을 막는다.
02 · 매출 드라이버로 본 5개 노드

공정 단계와 투자 노드는 같은 분류가 아니다. 하나의 stage 안에서도 ATE·접촉 인터페이스·핸들링·검사 장비가 동시에 쓰인다. 따라서 기업을 볼 때는 “어느 단계인가”와 함께 “무엇이 매출을 움직이는가”를 같이 봐야 한다.

NODE ①

Inspection · Metrology

드라이버: 검사 insertion · sampling

표면·범프·본딩·내부 결함을 공정 전후에서 측정한다. 2.5D에서 3D로 갈수록 숨은 계면과 접합 관리가 늘어난다.

KLA · Onto Innovation · CamtekKPI: tool of record · inspection steps · sampling · backlog
NODE ②

ATE

드라이버: test seconds · 칩 물량

전기 패턴을 인가해 메모리 셀·로직·TSV·링크의 기능과 속도를 판정한다. 테스트 시간이 늘고 병렬 효율이 따라오지 못하면 필요한 장비 수가 커진다.

Advantest · TeradyneKPI: test seconds · platform share · tester orders
NODE ③

Probe card · Socket

드라이버: 접촉 밀도 · ASP · 교체

DUT와 ATE 사이의 실제 전기 접점을 만든다. HBM4의 높은 I/O 밀도·고전류·열 요구가 접점 설계 난도와 qualification을 높인다.

FormFactor · MJC · Technoprobe 등KPI: card ASP · replacement · qualification · thermal/high-current mix
NODE ④

Prober · Handler

드라이버: 병렬 sites · thermal control

웨이퍼·다이·패키지를 정렬하고 이송하며 온도를 제어한다. die-level test와 고병렬·고전력 테스트로 갈수록 기계적·열적 정밀도가 중요해진다.

ACCRETECH · Cohu · AEM 등KPI: die-level 채택 · parallel sites · thermal option
NODE ⑤

OSAT · Test service

드라이버: 가동률 · advanced mix

조립과 테스트 라인을 실제로 운영한다. HBM·첨단 패키징 비중이 높아질수록 고급 패키징·테스트 믹스와 장비 가동률이 중요해진다.

ASE · Amkor 등KPI: utilization · advanced packaging/test mix
핵심 연결: HBM4는 electrical test 쪽에서 test seconds·접점·전력·열 부담을 키우고, 첨단 패키징은 inspection·metrology의 insertion을 앞단에 더 촘촘히 배치한다. 두 변화는 서로 다른 노드의 매출을 만들지만, 공통된 경제적 배경은 late-stage scrap을 피하려는 고객의 수율 보호다.
